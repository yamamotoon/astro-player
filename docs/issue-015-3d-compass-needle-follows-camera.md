# Issue #015: 3Dのコンパスボタンの針をカメラの向きに連動させる

## 状態

**実装済み。ブラウザでの動作確認待ち**

## 背景・課題

- 3Dの操作モード（方位磁石モードOFF）でドラッグしてカメラを回しても、コンパスボタンの針が真上に固定で、
  画面上のどちらが北か示せていない
- 方位磁石モードONでは、端末の向きからカメラの向きと針の向きをそれぞれ別々に決めており、二重管理になっている

## 要件

- 3Dのコンパスボタンの針は、方位磁石モードのON/OFFに関わらず、常にカメラの向きだけから決める
  （端末の向きはカメラ経由で針に反映される）
- 針は画面上の北を指す（Googleマップのコンパスと同じ考え方）
- 角度が±180°をまたいでも、針が逆回りに一周しないようにする
- 2Dは対象外（描画と針が同じ1つの値から決まっており、二重管理になっていないため今のまま）
