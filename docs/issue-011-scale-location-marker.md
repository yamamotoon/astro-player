# Issue #011: スケールモデルの位置マーカーを設定パネルの場所に連動させる

## 状態

**実装済み。ブラウザでの動作確認待ち**

## 背景・課題

- スケール系の画面の地球上の位置マーカー（赤い円錐）は、東京の緯度経度がコードに固定されており
  （`scaleModel3d.ts`の`TOKYO_LAT_DEG`/`TOKYO_LON_DEG`）、設定パネルの「場所」の入力を見ていない
- マーカーが小さく、地球上で見つけにくい

## 要件

### 1. 位置マーカーを設定パネルの緯度・経度に連動させる

- スケール系の画面に入った時点で、設定パネルの緯度・経度の位置にマーカーを置く
- 緯度・経度の入力を変えたら、その場でマーカーを動かす（3D+2D・SKYと同じく即時反映）
- 自転・公転・実比率/見やすく切替への追従は今のまま（マーカーは地球メッシュの子）
- 固定の東京座標の定数は削除する

### 2. 位置マーカーを大きくする

- 円錐の高さ・底面半径を今の4倍にする（高さ0.5→2.0、半径0.15→0.6）
- 見た目で大きすぎれば3〜5倍の範囲で調整する

### 3. 位置マーカーに若干の陰影を付ける

- 太陽光で陰影が付く材質にし、自己発光を足して影を控えめにする（夜側でも赤く見える）
- 陰影の強さは`scaleModel3d.ts`の`MARKER_EMISSIVE_INTENSITY`で調整する
