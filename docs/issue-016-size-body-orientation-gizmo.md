# Issue #016: 「スケール」画面で天体の向きを操作できるようにする

## 状態

**実装・確認済み**

## 背景・課題

- カメラは真正面固定・正投影で、操作は移動と拡大・縮小だけ。どの天体も赤道を真横から見た向きになる
- 土星の輪は赤道面にあるため、真横からでは線になり見えない。そのため土星だけを固定角度で傾けており、
  縞模様が真横向きの他の天体と見え方が食い違っていた。角度の値にも根拠がない
- 土星の輪が単色の板で、実物らしく見えない

## 要件

- 全天体の向きを一緒に回す UI（座標軸）を追加する
  - 座標軸は天体の向きと連動して表示する。触れる範囲が分かるよう、角丸の背景と縁取りを付ける
  - 座標軸の模型（倒れ具合と自転の具合を伝える。主役の天体と張り合わない）
    - 球はワイヤーフレーム（線だけ）で控えめな1色。経線12本・緯線5本（30度間隔）。奥半分の線は描かない
      （線だけだと手前と奥の区別がつかず、向きが反転して見えるため）
    - 座標軸は X=赤・Y=緑・Z=青。Yが自転軸で+Yが北極。プラス側は先端に点を付け、マイナス側は暗く描く。
      軸は球の奥に回っても隠さない
  - 座標軸を上下にドラッグすると天体を手前・奥に倒し、左右にドラッグすると自転の向きに回す
  - 初期の向きは18度手前に倒した状態（輪が見える程度。座標軸で傾きが見え、変えられるので値に厳密な根拠は求めない）
- 土星の輪は赤道面に置き、本体と一緒に回る
- 既存の操作（1本指/ドラッグで移動、2本指/ホイールで拡大・縮小、視点ダイアログ）は変えない
- 全体表示・天体に寄る時の範囲計算は、その時の向きでの土星の輪の大きさに合わせる
- 土星の輪に実際の構造（C環・B環・カッシーニの間隙・A環）の帯模様を付ける。細かすぎる模様にならない
  解像度にする
