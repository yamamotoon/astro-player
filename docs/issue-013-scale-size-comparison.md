# Issue #013: 「スケール」画面を天体の大きさ比較ビューに作り直す

## 状態

**実装済み。ブラウザでの動作確認待ち**

## 目的

「スケール」画面を、**太陽系の天体の大きさを見て比較する**ための画面に作り直す。
距離の正確さは不要。大きさの比率だけを正確に見せる。

「地球の公転」「地球の自転」画面は対象外（今のまま）。

## 要件

### 1. 表示する天体と並び

- 太陽・8惑星・冥王星を1列に並べる:
  太陽 → 水星 → 金星 → 地球 → 火星 → 木星 → 土星 → 天王星 → 海王星 → 冥王星
- 冥王星は準惑星と分かるようにする（ラベル等）
- 月は列に入れず、地球の横（列と90度の方向）に置く。衛星だと配置で伝わるようにする
- 大きさ（直径）は実際の比率。天体同士の間隔は実際の距離ではなく、見比べやすい間隔にする

### 2. 並べる向き

- 画面の長いほうに沿って並べる。縦長の画面なら縦（太陽が上）、横長の画面なら横（太陽が左）
- 画面の向き・大きさが変わったら並べる向きも切り替える
- 月は、縦に並べる時は地球の右、横に並べる時は地球の下
- 太陽は大きすぎるため、並びの先頭側の画面端から縁だけが見える形でよい（全体が入らなくてよい）

### 3. 時間

- 時間の要素は持たない。時間バーは出さず、天体は自転もしない静止表示

### 4. 操作

- 並びに沿った移動（スクロール）と拡大・縮小ができる
- 全体表示: 並び全体が見える状態に戻す
- 視点ダイアログで各天体にフォーカスできる。フォーカス時は、その天体が大きく映りつつ両隣の天体も
  画面に入る距離にし、大きさの対比が分かるようにする（地球の場合は月も入れる）

### 5. 見た目

- 土星には実際の比率の輪を付ける（輪の外径は本体直径の約2.35倍）
- 天体ごとにテクスチャ画像をあとから追加できる作りにする
- 太陽以外の天体のテクスチャは、ひと目でその天体と分かる特徴を描いた絵柄をスクリプトで生成する
  （`scripts/planet-texture/generate-planet-textures.py`）。地球・月は既存のテクスチャ
  - 縞模様: 木星（大赤斑）・土星・天王星・海王星（大暗斑・白い雲）・金星（雲の淡い筋）
  - 岩石: 水星（クレーター）・火星（暗い地域・極冠・マリネリス峡谷）・冥王星（ハート模様・暗い地域）

### 6. この画面で出さないもの

- 時間バー、設定パネル（歯車ボタン）

## 実装方式

- 新規ファイル`sizeComparison3d.ts`に専用クラスを作る（`scaleModel3d.ts`とは独立。公転・自転画面は引き続き`scaleModel3d.ts`）
- Three.jsの正投影カメラ（OrthographicCamera）で描く。画面上の位置に関わらず実際の比率どおりの大きさで映すため
- 操作はドラッグで移動、ホイール/ピンチで拡大・縮小（回転はしない）
- 画面に入るたびに作り、出る時に破棄する（スケール系の既存画面と同じ）
- 右上は「視点」（ダイアログ: 全体を見る・各天体に寄る）と全体表示ボタン
