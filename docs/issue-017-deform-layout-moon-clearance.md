# Issue #017: 「見やすく」表示で月の軌道が他の惑星の軌道と交差しないようにする

## 状態

**実装・確認済み**

## 背景・課題

- 地球の公転画面の「見やすく」表示で、月の軌道が金星の軌道と交差している。月は水星・火星とも、
  表面どうしが接するところまで近づく
- 原因：水星・金星・火星の位置は「となりの軌道との差を一定以上空ける」ことしか考えておらず、
  月が地球のまわりを回って動く範囲を考えていない
- 天体の大きさは全部同じで、すき間（表面から表面までの距離）の値にも根拠がない

## 要件

「見やすく」表示の大きさと距離を、次のルールで決める。「実比率」表示は変えない。

1. 大きさ
   - 地球を基準にする
   - 太陽は地球の2倍（実際の比ではないが、地球より大きいことを示す）
   - 月・水星・金星・火星は、実際の大小の順番を保ったまま差を縮める。月が地球の1/2になる縮め方を、
     他の惑星にも同じように当てる（結果：水星0.60・金星0.97・火星0.71）
2. 太陽からの距離
   - 太陽の表面から各惑星の表面までのすき間を、実際のすき間の比に合わせる
     （水星 : 金星 : 地球 : 火星 ≒ 0.38 : 0.72 : 1 : 1.53）
3. 月の軌道
   - 地球から月までの距離は、今の半分にする
   - 月は地球の地点ピンの先より外側を回る
4. 重ならないこと
   - どの日付・どの角度でも、天体どうし（公転で動く月を含む）の表面の間を最低5（地球の半径=10として）空ける
   - これを満たす最小の大きさまで、系全体（すき間の倍率）を広げる
5. 公転画面と自転画面の両方に適用する（どちらも同じ「見やすく」表示の値を使う）
6. 後から調整しやすくする
   - 配置パターン（実比率・見やすく）はデータで持つ。見やすく表示のデータは、各天体の半径・
     太陽側のとなりの天体とのすき間（地球は月の公転範囲の端から）・月の軌道の半径
   - 太陽からの距離は、半径とすき間を足し合わせて求める。すき間が0より大きい限り天体どうしは重ならない
   - 調整は、データの数字を書き換えるだけでできる

## 実装方針

- `orbitalMath.ts`：配置パターンの型（半径・太陽からの距離・月の軌道の半径）を作り、実比率と見やすくの
  2パターンを持つ。見やすくのパターンは、半径とすき間のデータから太陽からの距離を求めて作る。
  データの値は、要件1〜4のルールで求めた値を切りのよい数字にしたもの
- `scaleModel3d.ts`：「見やすくならこの値、実比率ならこの値」の切り替えをやめ、今の配置パターンから値を読む

## 確認方法

- 1日ごとに4年分の位置を計算し、天体どうし（月を含む）の表面の間が常に5以上あることを確かめる
- 画面で、公転画面・自転画面の「見やすく」表示と「実比率」への切替を確かめる
