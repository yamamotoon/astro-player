# Issue #012: スケール系画面の視点をダイアログで選べるようにする

## 状態

**実装済み（検証済み）。フォーカス・系全体ボタン廃止はブラウザでの動作確認待ち**

## 背景・課題

キャンバス右上のフォーカス・系全体・全体表示の3ボタンは、アイコンだけでは何の機能か直感的に分からない。

- フォーカスのアイコンは地図アプリの「現在地」、全体表示のアイコンはフルスクリーンに見える
- 機能名はツールチップにしか出ず、スマホでは押すまで分からない
- フォーカス・系全体は「選んでいる天体」を知らないと意味をなさない

分かりにくい機能は、文字で説明できるダイアログで選ばせる方式を試す。

## 進め方

1. ダイアログを**追加**し、使い勝手・分かりやすさを検証する（本issue）
2. 検証の結果を見て、既存のフォーカス・系全体ボタンの扱い（削除など）を決める。それまで既存ボタンは残す

## 要件

### 1. ダイアログを開くボタン

- キャンバス右上のボタン群の左端に、文字付きのボタン「視点」を置く

### 2. ダイアログ

- 画面中央に出るモーダルダイアログ。タイトルは「視点を選ぶ」
- 項目は「何が見えるか」を文言にした一覧:

  | 項目 | 動き（今の機能との対応） |
  |---|---|
  | 地球と月の軌道を見る | 対象を地球にして系全体 |
  | 地球の公転軌道を見る | 対象を太陽にして系全体 |
  | 太陽に寄る | 対象を太陽にしてフォーカス |
  | 地球に寄る | 対象を地球にしてフォーカス |
  | 月に寄る | 対象を月にしてフォーカス |
  | 水星/金星/火星に寄る | 対象をその惑星にしてフォーカス。水星・金星・火星を表示している画面（公転画面）だけ |

- 軌道を見る項目を上、天体に寄る項目を下にまとめる（寄る操作は使う頻度が低いため）
- 項目を選ぶと、その動きをしてダイアログを閉じる
- ダイアログの外側を押す・Escキー・閉じるボタンで、何もせずに閉じる

- 検証用なので日本語のみ（英語表示でも日本語のまま）。採用が決まったら英語対応する

### 3. 既存の操作

- フォーカス・系全体・全体表示ボタン、天体のタップ選択は今のまま残す

### 4. 検証結果を受けて: フォーカス・系全体ボタンを廃止する

ダイアログで満足できたため、キャンバス右上はダイアログを開く「視点」と全体表示の2つにする。

- フォーカス・系全体ボタンを削除する（HTML・i18nのツールチップ・アイコン`target.svg`/`orbit.svg`・関連処理）
- 天体のタップ選択は残す（追いかける天体を変える操作として）
- Enter/Fキー（対象に寄る）・Homeキー（全体表示）のショートカットは残す
- ダイアログを英語対応する（採用が決まったため）
