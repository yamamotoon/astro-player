# Issue #010: スケール系画面のタイトルバー見直し

## 状態

**実装済み。ブラウザでの動作確認待ち**

## 背景・課題

- ヘッダー中央に画面名が出るようになったため、スケール系画面のタイトルバー（`.view-title`）の
  タイトル文言が二重表示になっている
- タイトルバーの帯の分だけキャンバスの縦幅が減っている。3D+2D・SKYは帯を持たず、ボタンを
  キャンバス上に重ねている
- 実寸/デフォルメ切替ボタンが時間バー用の`.scale-mode-btn`（高さ40px・余白大）を流用しており、
  22pxのアイコンボタンの中で1つだけ大きすぎる
- 「実寸」という文言は天体の画面では意味が伝わりにくい
- キャンバス上端中央の日時表示（`.scale-date-hud`）が時間UIの日時ラベルと重複している

デフォルメ切替のアイコン化も検討したが、「実寸⇔デフォルメ」には定番の絵がなく、天体は描けても
デフォルメの意味が伝わらないため見送り、文字ボタンとする。

## 要件

### 1. タイトルバーの帯をなくし、3D+2Dを踏襲する

- `#scene-scale`の`.view-title`（帯）と`#scale-scene-title`（タイトル文言）を削除する。画面名はヘッダーに任せる
- ボタン群は3D+2Dと同じ`.view-actions`として、キャンバス右上に重ねる（高さ40px・間隔6px・横一列）
- 入口ごとのタイトル出し分け処理（`main.ts`の`scaleSceneTitle`/`scaleSceneTitleKey`と言語切替時の再表示）と、
  不要になるi18nキー（`view-scale`/`view-scale-orbit`/`view-scale-spin`）を削除する

### 2. デフォルメ切替ボタン

- 文言: 日本語「実比率」/「見やすく」、英語「To scale」/「Easy view」（今の状態を表示）
- 見た目: 高さ40px。枠・文字色・ホバー色は隣のアイコンボタンに揃える。見やすく（デフォルメ）中は今と同じ強調表示
- 横幅は長いほうの文言に合わせて固定し、切り替えで他のボタンの位置がずれないようにする
- 並びの左端に置き、アイコン群との間を少し空ける
- ツールチップ（`scale-deform-title`）も新しい文言に合わせる（例:「実比率⇔見やすく表示の切り替え」）

### 3. キャンバス上端中央の日時表示を削除する

- `#scale-date-hud`（HTML・CSS・`scaleModel3d.ts`の`dateHudEl`/`formatSimDateFull`）を削除する

### 4. 時間UIの日時ラベルを全モードで時刻付きにする

- 日・月・年の全モードで「YYYY-MM-DD HH:MM」を表示する（`simPlayback.ts`の`formatSimDate`）
- `simPlayback.ts`は共通なので、3D+2D・SKYの表示も同じく変わる
- NOWボタンの強調は、月・年モードでも1分ずれた時点でONになる（今の日モードと同じ動き）

### 5. フルスクリーンボタンを全画面から削除する

1ページに複数のコンテンツが並んでいた頃の名残で、画面ごとにコンテンツが1つになった今は不要。

- 3D・2D・SKY・スケール系すべてのフルスクリーンボタンと、全画面表示の処理・CSS・アイコンを削除する
- アイコンボタンの共通クラス名`.fullscreen-btn`を`.icon-btn`に改名する

### 6. 実比率/見やすくの切替を設定パネルへ移す

頻繁に切り替えるものではなく表示モードの設定なので、キャンバス上のボタンから設定パネルへ移す。

- スケール系の画面でもヘッダーの歯車ボタンを表示し、設定パネルを開けるようにする
- 設定パネルに「表示」の項目を追加し、`[実比率][見やすく]`の2択ボタンにする（日/月/年ボタンと同じ見た目）。
  スケール系の画面でだけ表示する
- 設定パネルの「場所」は、スケール系の画面でも表示する（位置マーカーとの連動はissue #011）
- キャンバス右上の実比率/見やすくボタンを削除する。右上は全体表示・フォーカス・系全体の3つになる

### 7. 後片付け

- 使われなくなるCSS（`.view-title`・`.view-title-actions`など）を削除する
- 関連箇所の古くなったコメント（`.scale-date-hud`のCSSコメントなど）を削除する
