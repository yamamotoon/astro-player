# Issue #014: SKYモードの太陽・月を大きく表示する

## 状態

**実装・確認済み**

## 背景・課題

SKYモードの太陽・月は実物の見かけの直径（約0.5°）で描いており、初期の視野（60°）では画面上の直径が
5px前後しかない。星の点（直径3px前後）の1.5倍ほどで、空の中で見つけにくい。

## 要件

- 太陽・月を6倍（見かけの直径約3°）に拡大する。初期の視野・画面高さ600pxで直径28px前後、星の約9倍
- ラベルは拡大した天体の縁から離して置く
- ズームに合わせて大きくなる挙動は今のまま（最大ズーム時は直径170px前後）。大きすぎる場合は
  画面上の大きさに上限を付けることを検討する

大きさは`ar.ts`の`SUN_MOON_RADIUS`で調整する。
