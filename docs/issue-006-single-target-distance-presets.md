# Issue #006: 注視点を天体1つに単純化し、距離をプリセット化する

## 状態

**実装・検証済み。issue #002の複数選択・issue #005の中間点追従を置き換えた。**

## 実装メモ

- `selected: Set<BodyKey>` → `targetBody: BodyKey`（常に天体1つ、既定値'sun'）に変更
- `handleTap()`は対象を置き換えるだけ（カメラは動かさない）。既に対象の天体を押した場合・
  何もない場所を押した場合は無視する
- `focusOnTarget()`（フォーカスボタン/Enter・Fキー）、`focusOnSystemView()`（系全体ボタン）を新設。
  系全体は`SATELLITE_ORBIT_RADIUS`（天体ごとの衛星の公転半径）を基準に計算し、月は
  エントリが無いため`updateTargetButtonsUI()`でボタン自体を隠す
- `focusOnSystemView()`の距離は「どの角度から見ても収まる」保証は持たせず、**今のカメラ視線方向を
  基準に**フィットする（`frameDistanceForOrbit()`）。回転しない前提でフィットし、後で手動回転して
  衛星が画面外に出た場合はユーザーが同じボタンを再度押して合わせ直す運用（ユーザー合意事項）。
  軌道（中心=対象天体、XZ平面上の半径`orbitRadius`の円）上の全点を走査せず、円上のneed(φ)の
  最大値を4本の単一正弦波の振幅の最大値として厳密に求める閉形式の式を導出し、ブルートフォース
  サンプリングとの数値一致で検証済み（誤差は浮動小数点誤差の範囲内）
- `updateCameraTracking()`は中心点の平均計算が不要になり、対象1体の位置を直接使うだけに単純化
- 起動時は`this.focusOnSystemView()`を呼ぶだけで、太陽(既定の対象)の系全体（地球の公転半径基準、
  日付に依存しない距離）からスタートする
- 単一対象への簡略化後もissue #005の追従ロジック（差分による平行移動）は同じ考え方のまま。
  実際のロジックを移植したテストで、追従中のオフセット保持・対象切り替え時のジャンプ防止・
  太陽（動かない天体）を対象にした場合の安定性を検証済み

## 背景

このアプリ（スケールモデル）の目的は、宇宙を自由に移動することではなく、**天体の仕組み
（大きさ・距離・公転運動など）を視覚的に把握しやすくすること**。この観点から、注視点・距離の
仕様を見直した。

## 合意した方針

### 1. 注視点は常に天体1つだけ（複数選択・中間点は廃止）

issue #002では複数の天体を選択でき、issue #005ではその中心点にカメラが追従していた。しかし
例えば地球・月の中間点を追従すると、月が地球を公転するにつれて中間点自体も揺れ動き、カメラも
一緒に揺れてしまう。**注視点を常に地球単体に固定すれば、地球は画面中心に静止したまま、月だけが
その周りを回って見える**ため、天体の仕組みを把握する目的にはこちらが適している。

- `selected`は複数選択可能な`Set<BodyKey>`から、常に天体1つを指す状態に変える
- 天体をタップ/クリックすると、（追加ではなく）その天体に**置き換わる**

### 2. 距離は連続ズームではなく、2つのプリセット＋微調整

「フォーカス」「系全体」の2つのボタンで距離をプリセット指定できるようにする。そこからの
ズーム（微調整）・回転操作は今まで通り自由に行える（プリセットは初期距離を決めるだけ）。

- **フォーカス**: 対象の天体自体をじっくり見る距離（今の`focusOn()`と同じ、天体自身の半径基準）
- **系全体**: 対象の天体の衛星の公転軌道が画面に収まる距離。**「今日の衛星の実際の位置」ではなく
  「衛星の公転半径そのもの」を基準に計算する**（issue #005で見つけた「今日の角度によって見え方が
  変わる」バグと同じ問題を避けるため）。ただし「どの角度から見ても収まる」保証は持たせず、
  **今のカメラ視線方向を基準**にフィットする（回転しない前提。回転して画面外に出た場合は
  もう一度ボタンを押して合わせ直す）
  - 太陽が対象 → 地球の公転半径(`EARTH_SUN_DIST`)を基準
  - 地球が対象 → 月の公転半径(`EARTH_MOON_DIST`)を基準
  - 月が対象 → 衛星が無いため「系全体」ボタンは**非表示**にする（衛星を持たない天体だと
    視覚的に学習できる、という効果も期待できる）

### 3. UI

- タップ/再タップの仕組みに3段階目を追加するのではなく、「フォーカス」「系全体」は**専用ボタン**
  として用意する
- キーボードショートカットは今回は用意しない。必要性を感じたら別途検討する
